# StunSlam Mod

A Fabric mod for Minecraft 1.21.1 that enhances gameplay with stun slams, attitude swaps, and auto lunge swaps. This mod allows players to perform stun slams, attitude swaps, and auto lunge swaps with customizable keybinds and delays.

## Features

- **Stun Slam**: Perform a stun slam by pressing the R key.
- **Attitude Swap**: Perform an attitude swap by pressing the T key.
- **Auto Lunge Swap**: Perform an auto lunge swap by pressing the Y key.
- **Fall Distance Swap**: Automatically swaps between breach and density modes based on fall distance.

## Installation

1. Install Fabric Loader for Minecraft 1.21.1.
2. Place the mod jar in the `mods` folder.

## Usage

1. Launch Minecraft with the Fabric Loader.
2. Press the R key to perform a stun slam.
3. Press the T key to perform an attitude swap.
4. Press the Y key to perform an auto lunge swap.
